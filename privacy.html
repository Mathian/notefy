2. Описание сервиса

Notefy — это приложение для создания заметок и управления задачами, работающее внутри мессенджера Telegram в виде Mini App. Сервис позволяет:

  • Создавать, редактировать и удалять текстовые заметки;
  • Управлять списком задач с приоритетами и сроками выполнения;
  • Синхронизировать данные между устройствами через ваш аккаунт Telegram.

3. Регистрация и аккаунт

Для использования Приложения необходима авторизация через Telegram. При первом входе:

  • Вы предоставляете свой номер телефона через Telegram-бота;
  • Система автоматически создаёт уникальный аккаунт, привязанный к вашему номеру телефона;
  • Номер телефона используется исключительно как идентификатор и не может быть изменён.

4. Правила использования

Пользователь обязуется:

  • Не использовать Приложение в противозаконных целях;
  • Не размещать контент, нарушающий законодательство;
  • Не предпринимать попыток взлома или несанкционированного доступа;
  • Не передавать свою уникальную ссылку третьим лицам.

  • Потерю данных вследствие технических сбоев;

  • Действия третьих сторон.

Политика конфиденциальности

Мы серьёзно относимся к защите ваших персональных данных.

Данные, которые мы собираем

  • Номер телефона — для создания уникального идентификатора аккаунта;
  • Telegram ID и имя пользователя — для идентификации в системе;
  • Контент заметок и задач — хранится в Firebase и доступен только вам;
  • Дата регистрации и активности — для технических целей.

Как мы используем данные

  • Предоставление функций Приложения;
  • Синхронизация данных между устройствами;
  • Техническая поддержка и устранение неполадок.

Хранение данных

Данные хранятся в Firebase (Google Cloud), расположенном в дата-центрах на территории ЕС и США. Соединение защищено SSL-шифрованием.

Ваши права

  • Доступ к своим данным — все данные видны вам в Приложении;
  • Удаление данных — обратитесь к нам через Telegram-бота;
  • Исправление данных — имя можно изменить в настройках профиля.

Контакты

По вопросам, связанным с конфиденциальностью, обращайтесь через Telegram-бота.
